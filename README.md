### PyForge

I wanted a Python IDE that doesn’t make my laptop sound like a jet engine, so I’m building one myself, from scratch, in Python.

PyForge is a lightweight alternative to PyCharm. It’s not trying to do everything. It just aims to open fast, run smooth, and let you write code without the bloat.

Heads up: it’s in alpha. The basics work, a lot is still missing, and things will break (and change) as I go. If you’re okay with that, hop in.

Why it exists

Light on resources, even on old or low-end machines
Written in Python, so you can read the code and tinker with it
Built by one dev, one feature at a time
